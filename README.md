# flowith

flowith 是一款基于 Tauri + React + Tailwind CSS 的桌面端节奏管理工具。
它像一间安静的数字书房：任务被归档，思考被沉淀，目标被持续追踪，界面保持克制留白。

## 项目宣言

学生时代的日常并不宏大，更多是待办、思考、通知和倒数这类微小而持续的节奏。flowith 诞生于这种经验之中，目标不是替代思考，而是为思考提供一个可被安放、可被回访的容器。

## 技术架构

### 后端层

后端采用 Rust 作为执行层，并通过 Tauri 封装为桌面壳体，主要负责：

- 本地数据读写与持久化
- 通知、托盘、窗口状态等系统交互
- 校园通知抓取、认证、重试与诊断
- 维持较低资源开销下的稳定运行

### 前端画布

前端以 React 组织状态，以 Tailwind CSS 构建响应式界面，重点不在信息密度，而在阅读节奏：

- 组件化拆分倒计时、待办、学习体会、校园通知与快速入口
- 响应式网格承载面板伸缩关系
- 纸感留白、低对比阴影和缓慢过渡维持低噪声视觉环境

### 关键工程机制

#### 压迫特征纵轴尺寸测量机制

`useContentMinSize` 通过极窄视口下的内容克隆测量最小高度，将横向排版压力与纵向高度需求解耦，减少布局回写导致的循环锁死。

#### 时区不变性状态机

倒计时模块围绕本地运行时的时区序列化处理，尽量避免空数组谓词和时间边界带来的语义偏差。

## 核心功能形态

### 倒计时管理

倒计时采用纸张化卡片设计，并受最大边界约束，避免内容过度压缩或长宽比失衡。

### 每日学习体会

学习体会模块将输入区处理为大行高、无边框的 Markdown 沙盒，用于安静地归档当天思考。

### 待办事项

待办模块采用内联轴流式重排，保持输入、列表与状态变化之间的连续性；完成后会触发空状态回响。

## 视觉美学规范

flowith 的视觉系统受极简主义与数字冥想空间启发，目标是让界面可久坐、可停留、可思考。

### 色调体系

- 大面积象牙白面板悬浮于淡米色画布之上
- 通过低饱和暖色维持纸感与手账感
- 避免高刺激对比色长期占据视野中心

### 空间物理学

- 采用 20px - 24px 的宏大网格间距
- 以微弱高扩散阴影替代刚性边框
- 通过缓慢位移动效模拟水滴流动般的平滑过渡

## 功能概览

- **系统托盘**：支持最小化到托盘，并自动保存与恢复窗口状态
- **待办事项**：新增、提醒、完成态展示、通知提醒、空状态名言
- **每日学习体会**：本地 Markdown 保存，支持自定义目录
- **校园通知**：支持 URL 与选择器配置，支持 Cookie / 账号密码认证抓取，支持正文详情阅读与静默刷新。默认选择器基于中国农业大学 (CAU) 通知门户，其他学校请自行替换 URL 与选择器配置
- **快速入口**：自定义书签卡片，本地持久化，自动 favicon 兜底
- **倒计时**：支持新增、删除与主界面展示

## 运行环境

- Node.js 18 或更高版本
- Rust 与 Cargo
- macOS / Windows / Linux

## 本地运行

```bash
npm install
npm run tauri dev
```
